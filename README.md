# Catch a Film Studio — Sitio web

Sitio de la productora **Catch a Film Studio**. Se despliega en Hostinger (carpeta `public_html`) vía Git.

- `index.html` — sitio (home + portafolio, una sola página por ahora).
- Se edita desde el proyecto de trabajo y se publica con `git push` → Hostinger jala los cambios.
